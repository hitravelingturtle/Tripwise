Account security

Tripwise uses email and password login. Anyone can create an account from the sign-in screen.

Email login
Users can create their own account from the Tripwise login screen. Administrators then add registered accounts to trips. Never store passwords in Tripwise data.

If a user forgets a password, they can also use Forgot password? on the sign-in screen. An administrator can reset another user from Firebase Console → Authentication → Users.
