Tripwise Travel Expense Manager

Tripwise is a mobile-ready travel expense dashboard for international trips, road trips, treks, weekends, local trips and group expenses.

Included

  • Responsive mobile dashboard, versioned as v0.9.3
  • Installable PWA files: manifest.webmanifest, sw.js, icon.svg
  • Multiple trips and selected-trip dashboard
  • Group trip people list
  • Equal expense splitting between selected people
  • Search, filters, budget tracking, category analytics and CSV export
  • Firebase Hosting config: firebase.json
  • Firebase Web configuration template: firebase-config.js
  • Secure starter Firestore rules: firestore.rules
  • Complete deployment guide: FIREBASE_GITHUB_SETUP.html

Run locally

python3 -m http.server 4173

Open http://localhost:4173.

Deploy to Firebase

npm install -g firebase-tools
firebase login
firebase use --add
firebase deploy --only hosting

GitHub

git init
git add .
git commit -m "Initial Tripwise app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/tripwise.git
git push -u origin main

The app is Firebase-first: after you paste your Firebase Web configuration and enable Authentication and Firestore, accounts, trips and expenses are stored in Cloud Firestore. No trip data is stored in browser local storage. Follow FIREBASE_GITHUB_SETUP.html for the browser-only GitHub and Firebase setup.
